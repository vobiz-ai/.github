# Vobiz

Vobiz provides programmable voice APIs, SIP trunking, phone numbers, real-time audio streaming, and integrations for AI voice applications.

## Start building

1. Create an account in the [Developer Console](https://console.vobiz.ai).
2. Follow the [documentation introduction](https://vobiz.ai/docs/introduction) and quick-start guides.
3. Use the [OpenAPI specification](https://vobiz.ai/openapi.json), an official SDK, or the REST API directly.

AI coding tools can connect to the hosted [Vobiz documentation MCP server](https://vobiz.ai/docs/mcp) or install the reusable [Vobiz Agent Skills](https://github.com/vobiz-ai/Agent-Skills).
